# Data Dictionary

| Column | Description |
|---|---|
| kitchen_id | Unique kitchen record identifier |
| community | Community / locality name |
| lpg_kg_used | LPG consumed during the reporting period, kg |
| meals_served | Meals prepared/served during the reporting period |
| lpg_delivered_kg | LPG delivered during the reporting period, kg |
| days_in_period | Length of reporting period |
| delivery_gap_days | Days since/attributable to delivery gap |
| stove_condition_score | 0–100 condition score; higher is better |
| regulator_condition_score | 0–100 condition score; higher is better |
| hose_condition_score | 0–100 condition score; higher is better |
| cylinder_change_count | Number of cylinder changes in period |
| cooking_hours_day | Average cooking hours per day |
| storage_condition_score | 0–100 storage-condition score; higher is better |
| equipment_age_years | Approximate age of primary gas equipment |
| reported_odor_events | Count of reported odor events |
